* Main objective: generate a GUI for image3kit and pnmkit in order to make them easier to use

The image3kit has been a cmd-based app that writes files into disk, no interactive workflow. The idea is to create a GUI for it, in a way it can be used interactively, but keep the command-line interface as the core of it.

The idea is to create a minimal one based on the dering_segment.py. The img variable needs to be cached (persistant between different GUI actions).

We want the UI to allow editing the workflow via a code editor, and widgets for visualization. I haven't decided yet. jupyter notebooks and streamlit are among the candidates.


Widgets:
* Python code editor with syntax highlighting
* A section with that renders the png files generated by:
`plotAll_save(img, filename="volu_original", save=False)` , maybe skipping the saving and rendering directly from the memory, 

 * A widget that shows printInfo() values, in a collapsible widget, with an option for auto-update?
